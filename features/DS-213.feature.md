DS-213's description is empty. The issue is the clone source of DS-214, whose story is: opening Settings, clicking Add User, and entering name, email, password, and role. Locators below match the Settings page objects already used by DS-214 against `https://test.didaxis.studio`.

---

Feature: Add user in Settings (DS-213)

# Happy paths

Scenario: Open the Add User dialog from Settings
  Given I am logged in as admin
  When I navigate to the Settings page
  And I click "Add User"
  Then the "Add User" dialog is visible
  And I see fields Name, Email, Password, and Role
  And I see the "Create User" button

Scenario: Create a user with name, email, password, and EDITOR role
  Given I am on the Settings page
  And I opened the "Add User" dialog
  When I fill in Name, Email, Password, and Role "EDITOR"
  And I click "Create User"
  Then the dialog closes
  And the users table shows that name, email, and role EDITOR

# Negative

Scenario: Create User stays disabled when required fields are empty
  Given I opened the "Add User" dialog
  When I leave Name, Email, and Password empty
  Then the "Create User" button is disabled

Scenario: Closing the dialog without submitting does not add a user
  Given I opened the "Add User" dialog
  When I fill Name, Email, and Password
  And I close the dialog without clicking "Create User"
  Then the users table does not show that email

# Edge cases

Scenario: Create a user with ADMIN role
  Given I opened the "Add User" dialog
  When I fill Name, Email, Password, and Role "ADMIN"
  And I click "Create User"
  Then the users table shows role ADMIN for that user
