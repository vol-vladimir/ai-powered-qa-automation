# DS-215 — MASHA: User should be able to add user in Settings TK

**Jira:** [DS-215](https://legionqaschool.atlassian.net/browse/DS-215) — MASHA: User should be able to add user in Settings TK

DS-215's description is empty. The title matches DS-213 and its clone DS-214: a user opens Settings, clicks Add User, and enters name, email, password, and role. Locators match the Settings page objects verified against `https://test.didaxis.studio`.

---

Feature: Add user in Settings (DS-215)

# Happy paths

Scenario: Open the Add User dialog from Settings
  Given I am logged in as admin
  When I navigate to the Settings page
  And I click "Add User"
  Then the "Add User" dialog is visible
  And I see fields Name, Email, Password, and Role
  And I see the "Create User" button

Scenario: Create a user with name, email, password, and VIEWER role
  Given I am on the Settings page
  And I opened the "Add User" dialog
  When I fill in Name, Email, Password, and Role "VIEWER"
  And I click "Create User"
  Then the dialog closes
  And the users table shows that name, email, and role VIEWER

# Negative

Scenario: Create User stays disabled when only Name is filled
  Given I opened the "Add User" dialog
  When I fill Name and leave Email and Password empty
  Then the "Create User" button is disabled
  And the dialog remains open

Scenario: Closing the dialog without submitting does not add a user
  Given I opened the "Add User" dialog
  When I fill Name, Email, and Password
  And I close the dialog without clicking "Create User"
  Then the users table does not show that email

# Edge cases

Scenario: Email local part may contain a plus tag
  Given I opened the "Add User" dialog
  When I fill an email whose local part contains a plus tag
  And I fill Name, Password, and Role "EDITOR"
  And I click "Create User"
  Then the users table shows that email
