# DS-215 — MASHA: User should be able to add user in Settings TK

**Jira:** [DS-215](https://legionqaschool.atlassian.net/browse/DS-215)  
**Story:** AS A user I would expect when Opening Settings page click button add user. This should open a dialog where I can add users name, email, password and role. (Same acceptance criteria as DS-214 — verified against https://test.didaxis.studio.)

**App surface:**
- Route: `/settings`
- Nav: button `⚙️ Settings`
- Users section: heading `Users`, button `Add User`, users table (Name / Email / Role / Active)
- Dialog: `Add User` with textboxes Name, Email, Password, Role (options ADMIN / EDITOR / VIEWER), button `Create User`
- Close dialog via the dialog banner close control (no Cancel button)

# Happy paths

Scenario: Navigate to Settings and open Add User dialog
  Given I am logged in as admin at https://test.didaxis.studio
  When I navigate to the Settings page at /settings
  And I click "Add User"
  Then the "Add User" dialog is visible
  And I see the Name field
  And I see the Email field
  And I see the Password field
  And I see the Role field
  And I see the "Create User" button

Scenario: Successfully create a user with name, email, password, and EDITOR role
  Given I am logged in as admin
  And I am on the Settings page
  And I opened the "Add User" dialog
  When I fill in Name with "QA Jordan Lee ds215"
  And I fill in Email with "qa-ds215-jordan@college.edu"
  And I fill in Password with "Password1!"
  And I select Role "EDITOR"
  And I click "Create User"
  Then the dialog closes
  And the users table shows a row for "QA Jordan Lee ds215"
  And the row shows email "qa-ds215-jordan@college.edu"
  And the row shows role "EDITOR"

Scenario: Create user with ADMIN role
  Given I am logged in as admin
  And I opened the "Add User" dialog
  When I fill Name "QA Admin User ds215", Email "qa-ds215-admin@college.edu", Password "Password1!", Role "ADMIN"
  And I click "Create User"
  Then the dialog closes
  And the users table shows role "ADMIN" for that user

Scenario: Create user with VIEWER role
  Given I am logged in as admin
  And I opened the "Add User" dialog
  When I fill Name "QA Viewer User ds215", Email "qa-ds215-viewer@college.edu", Password "Password1!", Role "VIEWER"
  And I click "Create User"
  Then the dialog closes
  And the users table shows role "VIEWER" for that user

# Negative

Scenario: Create User stays disabled when required fields are empty
  Given I am logged in as admin
  And I opened the "Add User" dialog
  When I leave Name, Email, and Password empty
  Then the "Create User" button is disabled
  And no new user row is added

Scenario: Create User stays disabled when only Name is filled
  Given I am logged in as admin
  And I opened the "Add User" dialog
  When I fill Name with "Incomplete User"
  And I leave Email and Password empty
  Then the "Create User" button is disabled

Scenario: Closing the dialog without submitting does not add a user
  Given I am logged in as admin
  And I opened the "Add User" dialog
  When I fill Name "Discarded User", Email "qa-ds215-discard@college.edu", Password "Password1!"
  And I close the dialog via the banner close control
  Then the dialog is hidden
  And the users table does not show "qa-ds215-discard@college.edu"

# Edge cases

Scenario: Create user with unique email containing plus-tag style local part
  Given I am logged in as admin
  And I opened the "Add User" dialog
  When I create a user named "QA Plus Email ds215" with email "qa-ds215-plus+tag@college.edu", password "Password1!", role "EDITOR"
  Then the user appears in the users table with that email

Scenario: Role defaults to EDITOR when dialog opens
  Given I am logged in as admin
  When I open the "Add User" dialog
  Then the Role field shows "EDITOR"
